# Будинок Ані (newyearania)

Новорічна гра-прикрашалка для iPhone: веб-гра (PWA) на Phaser 3 + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173, також доступна з телефона у тій самій Wi-Fi мережі
npm run build     # збірка в dist/
npm run preview   # перевірити збірку
```

## Як додати на iPhone

1. Розмістити `dist/` на безкоштовному хостингу з HTTPS (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Відкрити посилання в **Safari** на її айфоні.
3. «Поділитися» → «На початковий екран». Гра запускається повноекранно й працює офлайн.

Збереження (монетки, предмети, розстановка, цілі, рекорд) лежить у localStorage цього пристрою.

## Що вже є

- 5 кімнат: спальня, кухня, балкон, гараж, сад (зі скетчів)
- Аня в новорічній шапці ходить: тап по кімнаті
- Інвентар: тап або перетягни предмет у кімнату; щоб прибрати — перетягни вниз
- Магазин: 4 категорії, 22 предмети, покупка за монетки (старт: 100)
- Зірочки: 1 за кожні 2 предмети в кімнаті, до 3 на кімнату; за кожну нову зірочку +5 монеток
- **Робота «Гірлянда»** (💡): гра на пам'ять без таймера — повтори послідовність вогників.
  Монетки = довжина кожної повтореної послідовності, +10 за новий рекорд
- **Цілі**: банер у кімнаті завжди показує, що робити далі (`src/goals.ts`), нагорода монетками
- **Звуки** (синтезовані через Web Audio, без файлів), кнопка 🔊/🔇 зверху
- Збереження, PWA (manifest, service worker, іконки)

## Структура

- `src/config.ts` розміри та розмітка екрана (780×1520, масштаб FIT)
- `src/rooms.ts` кімнати та вбудований декор
- `src/items.ts` каталог предметів і цін
- `src/state.ts` стан гри, збереження та міграція старих збережень
- `src/goals.ts` цілі та виплата нагород
- `src/sound.ts` звукові ефекти (Web Audio)
- `src/scenes/RoomScene.ts` кімната, героїня, інвентар, банер цілі
- `src/scenes/ShopScene.ts` магазин
- `src/scenes/GarlandScene.ts` міні-гра «Гірлянда»
